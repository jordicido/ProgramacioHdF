# Ejercicios de Listas — Nivel intermedio


### **1. Encontrar el número mayor**

Dada la lista:

```python
numeros = [4, 7, 1, 9, 3]
```

Encuentra y muestra el número mayor usando un bucle.

(No uses max().)

---

### **2. Comprobar si la lista está ordenada**

Dada la lista:

```python
numeros = [3, 5, 7, 9, 12]
```

Comprueba si los números están ordenados de menor a mayor.
Si lo están, muestra `"Está ordenada"`.
Si no, muestra `"No está ordenada"`.

---

### **3. Calcular la media**

Dada la lista:

```python
notas = [6, 8, 5, 9, 7]
```

Calcula la **media** usando un bucle.

---

### **4. Contar mayores que la media**

Usando la misma lista:

```python
notas = [6, 8, 5, 9, 7]
```

Cuenta cuántas notas están **por encima de la media**.

---

### **5. Crear una nueva lista con números pares**

Dada la lista:

```python
numeros = [1, 4, 7, 8, 10, 13]
```

Crea una nueva lista llamada `pares` que contenga solo los números pares.

---

### **6. Contar veces que aparece un número**

Dada la lista:

```python
numeros = [2, 5, 2, 8, 2, 9]
```

Cuenta cuántas veces aparece el número `2`.
(No uses `count()`.)

---

### **7. Invertir una lista (sin usar reverse)**

Dada la lista:

```python
numeros = [1, 2, 3, 4, 5]
```

Crea una nueva lista que contenga los mismos elementos pero en orden inverso.
(No uses `reverse()` ni slicing avanzado.)

---

### **8. Multiplicar todos los elementos**

Dada la lista:

```python
numeros = [2, 3, 4]
```

Calcula el **producto total** de todos los elementos.

---

### **9. Comparar dos listas**

Dadas las listas:

```python
lista1 = [1, 2, 3]
lista2 = [1, 2, 4]
```

Compara elemento por elemento y muestra en qué posición son diferentes.

---

### **10. Eliminar números negativos**

Dada la lista:

```python
numeros = [3, -1, 7, -5, 9, -2]
```

Crea una nueva lista que contenga solo los números **positivos**.
