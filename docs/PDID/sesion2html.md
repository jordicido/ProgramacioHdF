# PRÁCTICA 2 - Enlaces y listas en HTML

## Objetivo

- Organizar información mediante listas.
- Crear enlaces para navegar entre páginas web.

## Teoría mínima

Las listas en HTML se utilizan para organizar información de manera estructurada. Hay dos tipos principales de listas:

- Listas desordenadas (`<ul>`): Se utilizan para elementos que no tienen un orden específico. Cada elemento de la lista se define con `<li>`.
- Listas ordenadas (`<ol>`): Se utilizan para elementos que tienen un orden específico. Cada elemento de la lista se define con `<li>` y se numeran automáticamente.

Los enlaces en HTML se crean con la etiqueta `<a>`. El atributo `href` se utiliza para especificar la URL del destino del enlace. Por ejemplo:

```html
<a href="https://www.ejemplo.com">Visitar ejemplo.com</a>
```
