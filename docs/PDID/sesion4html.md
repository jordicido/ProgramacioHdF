# Práctica 4 - Organización de la web con secciones y divs

## Objetivo

- Aprender a organizar el contenido de una página web usando secciones y divs.

## Teoría mínima

En HTML, se pueden usar elementos de sección como `<section>`, `<article>`, `<nav>`, `<aside>`, etc., para organizar el contenido de una página web de manera semántica. Estos elementos ayudan a estructurar el contenido y a mejorar la accesibilidad.

El elemento `<div>` es un contenedor genérico que se utiliza para agrupar otros elementos y aplicar estilos o scripts a ellos. A diferencia de los elementos de sección, `<div>` no tiene un significado semántico específico.

## Tarea 1

Organiza tu página en bloques:

- cabecera (título)
- contenido principal
- pie de página

Puedes usar `<div>` para crear estos bloques o bien usar elementos de sección como `<header>`, `<main>` y `<footer>`.
