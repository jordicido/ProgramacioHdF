# Conceptos básicos de imagen digital

En esta página aprenderás cómo están hechas las imágenes digitales y los conceptos esenciales para trabajar con ellas. Dominar estas ideas te ayudará después a editar, retocar y componer imágenes de manera más eficaz.

---

## 1. Imagen raster y vectorial

### 1.1. ¿Qué es una imagen raster?

Una imagen **raster** (también llamada *mapa de bits*) está formada por miles o millones de **píxeles**.  
Es el tipo de imagen más habitual: fotografías, capturas de pantalla, imágenes de redes sociales…

- Cada píxel tiene un color.
- Si ampliamos mucho la imagen, veremos “cuadraditos”.
- Al hacer demasiado zoom, la imagen **pierde calidad** (se pixela).

Ejemplos:
- Fotos tomadas con el móvil.
- Imágenes de Instagram o TikTok.
- Fondos de pantalla.

---

### 1.2. ¿Qué es una imagen vectorial?

Una imagen **vectorial** no usa píxeles, sino **líneas, formas y operaciones matemáticas**.  
Da igual cuánto la amplíes: **siempre se verá nítida**.

Se usa principalmente para logos, iconos e ilustraciones.

- No pierde calidad al ampliar.
- Se puede escalar todo lo que quieras.
- Es ideal para diseño gráfico y cartelería.

Ejemplos:
- Iconos de aplicaciones.
- Logotipos de marcas.
- Ilustraciones digitales.

---

## 2. Píxeles y resolución

### 2.1. ¿Qué es un píxel?

Un **píxel** es la unidad mínima de una imagen digital.  
Es como una baldosa en un mosaico: una pieza pequeña que, junto a muchas otras, forma una imagen completa.

Cuando haces zoom en una imagen y ves “bloques de color”, eso son píxeles.

---

### 2.2. ¿Qué es la resolución?

La **resolución** de una imagen indica cuántos píxeles tiene en ancho y alto.

Ejemplos:
- 1920 × 1080 → Full HD  
- 1080 × 1080 → formato cuadrado  
- 3840 × 2160 → 4K

Más píxeles = mejor calidad (hasta cierto punto).

---

### 2.3. Tamaño de archivo vs tamaño en píxeles

**No es lo mismo:**

- **Tamaño de imagen (en píxeles):** ejemplo: 1200 × 800  
- **Tamaño de archivo (en MB o KB):** ejemplo: 2,1 MB  

Una imagen puede tener:
- muchas dimensiones pero pesar poco, o  
- pocas dimensiones pero pesar mucho.  

Depende del **formato** y la **compresión**.

---

## 3. PPI / DPI (densidad de píxeles)

- **PPI:** píxeles por pulgada → pantallas  
- **DPI:** puntos por pulgada → impresoras  

Para pantallas, 72–96 PPI suelen ser suficientes.  
Para impresión de buena calidad, se suele usar **300 PPI**.

---

## 4. Formatos de imagen

### 4.1. JPG

- Perfecto para fotos.
- Ocupa poco espacio gracias a la **compresión con pérdida**.
- No permite transparencia.

### 4.2. PNG

- Permite **transparencia**.
- Ideal para logotipos y elementos decorativos.
- Suele pesar más que un JPG.

### 4.3. GIF

- Permite animación simple.
- Pocos colores, calidad limitada.

### 4.4. SVG

- Formato vectorial.
- Nunca se pixela.
- Perfecto para iconos y logotipos.

### 4.5. WebP

- Formato moderno optimizado para la web.
- Buena calidad con poco peso.

---

## 5. ¿Por qué necesitas comprender todo esto?

Porque cuando edites imágenes:

- elegirás mejor los recursos,
- evitarás usar imágenes pixeladas,
- sabrás cuándo usar PNG o JPG,
- podrás crear composiciones con buena calidad visual.
- entenderás las limitaciones y ventajas de cada formato.
