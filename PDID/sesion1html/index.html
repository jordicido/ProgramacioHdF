    PRÁCTICA 1 — Estructura básica HTML

    Objetivo

    Crear tu primera página web con la estructura básica de HTML.

    Teoría mínima

    HTML (HyperText Markup Language) es el lenguaje de marcado que se utiliza para crear páginas web. Un documento HTML está formado por una serie de elementos que se organizan en una estructura jerárquica. La estructura básica de un documento HTML es la siguiente:

    <!DOCTYPE html>
<html>
<head>
    <title>Título de la página</title>
</head>
<body>
    <h1>Encabezado principal</h1>
    <p>Este es un párrafo de texto.</p>
</body>
</html>
    • <!DOCTYPE html>: Indica que el documento es un documento HTML5.
    • <html>: Es el elemento raíz que contiene todo el contenido de la página.
    • <head>: Contiene información meta sobre el documento, como el título, enlaces a hojas de estilo, scripts, etc.
    • <title>: Define el título de la página que se muestra en la pestaña del navegador.
    • <body>: Contiene el contenido visible de la página, como texto, imágenes, enlaces, etc.
    • <h1>: Es un encabezado de nivel 1, utilizado para títulos principales.
    • <p>: Es un párrafo de texto.

    Tarea 1

    Crea un archivo llamado index.html con:

    • estructura completa HTML
    • un título en la pestaña (<title>)
    • un encabezado principal (<h1>)
    • un párrafo (<p>) con una breve descripción de ti mismo o de tu asignatura favorita.

    El contenido debe ser sobre ti o inventado, pero debe ser apropiado para un entorno educativo. Puedes incluir información como tu nombre, tus intereses, tu asignatura favorita, etc.

    Tarea 2

    Aprender a estructurar contenido con encabezados y párrafos.

    Modifica tu index.html y añade:

    • un <h1> (título principal)
    • un <h2> (subtítulo)
    • al menos 2 párrafos (<p>)

    Tema: “Sobre mí”

    • Debe tener sentido como texto (no frases sueltas)
    • Debe estar bien organizado con los encabezados y párrafos.

    Reto

    Usa <strong> para destacar algo importante Usa <em> para enfatizar una palabra

    Entrega

    Sube tu archivo index.html a aules y compártelo con tu profesor. Asegúrate de que el archivo se llama index.html y que tiene la estructura básica de HTML.
