    Ejercicios básicos de Listas

    1. Crea una lista llamada numeros con los valores:

    5, 10, 15, 20

    Muéstrala por pantalla.

    2. Dada la lista:

    colores = ["Rojo", "Verde", "Azul"]
    • Muestra el primer elemento.
    • Muestra el último elemento.

    3. Dada la lista:

    animales = ["Perro", "Gato", "Pájaro"]

    Cambia "Gato" por "Conejo" y muestra la lista completa.

    4. Crea una lista vacía llamada notas.

    Añade tres números usando .append() y muestra la lista.

    5. Dada la lista:

    dias = ["Lunes", "Martes", "Miércoles", "Jueves"]

    Muestra cuántos elementos tiene usando len().

    6. Dada la lista:

    nombres = ["Ana", "Luis", "Marta", "Carlos"]

    Muestra todos los nombres usando un for.

    7. Dada la lista:

    numeros = [3, 7, 2, 9, 4]

    Cuenta cuántos números hay en la lista usando un bucle. (No uses directamente len() para contar.)

    8. Dada la lista:

    numeros = [10, 20, 30, 40]

    Calcula la suma total usando un bucle.

    9. Dada la lista:

    numeros = [1, 4, 7, 8, 10, 13]

    Cuenta cuántos números son pares.

    10. Dada la lista:

    nombres = ["Ana", "Luis", "Marta", "Carlos"]

    Comprueba si "Marta" está en la lista. Si está, muestra "Encontrado".

    11. Pide al usuario 5 números y guárdalos en una lista usando .append().

    Después muestra la lista completa.

    12. Dada la lista:

    numeros = [2, 8, 1, 6, 3, 9]

    Muestra solo los números mayores que 5 usando un bucle.
